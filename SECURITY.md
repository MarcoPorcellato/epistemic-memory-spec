# Security policy

This repository currently ships no production runtime, hosted service, or deployable package.

Please do not place sensitive material in public issues. This includes private vault content, prompts, credentials, personal data, and undisclosed vulnerabilities.

For account or repository security concerns, use GitHub's private reporting route when available. If no private route is available, do not disclose sensitive details publicly; contact the maintainer through the GitHub profile to identify a safe route.

Research claims and ordinary draft issues should use the public issue forms and synthetic or redacted evidence.
