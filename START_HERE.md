# Start Here

## First: status and boundaries

Read [STATUS.md](STATUS.md) before treating any term as a requirement.
This is a pre-standard research draft, not a protocol, conformance suite,
reference implementation, or compatibility claim.

## Researcher path

Read [the draft](spec/epistemic-memory-research-draft-v0.md), then
[PROVENANCE.md](PROVENANCE.md). Submit primary sources or terminology
corrections through the issue chooser.

## Future implementer path

Read [CHARTER.md](CHARTER.md), [VERSIONING.md](VERSIONING.md), and
[docs/evidence-and-review.md](docs/evidence-and-review.md). Use only synthetic
or redacted material. Do not claim compatibility or conformance.

## Critical-review path

Read [CHARTER.md](CHARTER.md) and [OPEN_RESEARCH.md](OPEN_RESEARCH.md), then
use the issue chooser for a counterexample, privacy concern, or reproducible
critique.

Also see [Discussion #7](https://github.com/MarcoPorcellato/epistemic-memory-spec/discussions/7),
[the issue chooser](https://github.com/MarcoPorcellato/epistemic-memory-spec/issues/new/choose),
and [CONTRIBUTING.md](CONTRIBUTING.md).
